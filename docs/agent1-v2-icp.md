# Magic Script V2 — Agent 1 ICP

Status: FROZEN FOR IMPLEMENTATION

Active geography:
MARTINIQUE

Future only:
- Guadeloupe
- Guyane

Core principle:

Agent 1 does NOT find arbitrary companies without websites.

It finds local businesses where Magic Script can make a MATERIAL commercial improvement.

Prospect evaluation must consider:

1. BUSINESS FIT
2. DIGITAL PAIN
3. MAGIC SCRIPT CAPABILITY
4. DECISION AUTHORITY
5. CONTACTABILITY

Canonical outcomes:

ADMIT
CAPABILITY_GATED
QUALITY_GATED
NEEDS_CONTACT_DISCOVERY
REJECT

ADMIT requires:
- valid business fit
- clear digital/commercial pain
- Magic Script can solve it
- sufficient local decision authority
- valid EMAIL or deterministically classified MOBILE

CAPABILITY_GATED:
use when the business is attractive but meaningful improvement requires currently unproven capability, including:
- full e-commerce
- checkout/payment
- live inventory
- complex catalogue integration
- advanced booking inventory
- vehicle availability/reservation

QUALITY_GATED:
use when the existing site is already professionally designed, agency-grade, modern, strongly responsive, professionally maintained, or supported by internal marketing.
These prospects cannot enter active production while the Website Quality Gate is CLOSED.

NEEDS_CONTACT_DISCOVERY:
valid target + digital pain but no qualifying EMAIL or MOBILE yet.
Landline/social/contact-form alone do not qualify for admission.
Agent 1 may keep searching for qualifying contact data.

REJECT:
no meaningful commercial improvement, outside ICP, no decision authority, already-good site with no material gap, or unsuitable business model.

Active production:
maximum 20 prospects.
20 is a CAPACITY LIMIT, never a fill target.
Prefer 7 excellent prospects over 20 weak ones.

Only admitted active-slot holders may trigger:
Designer
→ Senior Design Director
→ Builder
→ Visual QA
→ Proposal

Search cadence/backlog quantity are NOT frozen here.

Launch priority:
EASY WINS.

- no useful website
