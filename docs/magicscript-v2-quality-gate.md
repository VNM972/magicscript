# Magic Script V2 — Website Quality Gate

Status: FROZEN FOR IMPLEMENTATION

QUALITY GATE: CLOSED

This document governs WEBSITE DESIGN / UX / COMMERCIAL PRESENTATION QUALITY.

It is NOT:
- linting
- unit tests
- build validation
- CI/CD
- a generic engineering merge gate

Purpose:

Prevent Agent 1 from challenging already-professional websites until Magic Script V2 proves repeatable professional-quality website output.

The gate exists because V1 visual quality was not proven reliable enough.

QUALITY BAR:

VISUAL
- professional composition
- consistent spacing
- typography hierarchy
- restrained colour use
- coherent sections
- no repetitive block spam
- no obvious AI-generated design feel
- no generic-template appearance
- strong first viewport
- credible desktop/mobile presentation

UX
- clear navigation
- clear primary CTA
- logical information architecture
- no dead ends
- no unnecessary density
- no meaningless decoration
- rapid understanding of business/value

COMMERCIAL
- clear business proposition
- clear reason to choose business
- clear visitor action
- relevant trust/proof
- CTA appropriate to business model

CONTENT
- no invented claims
- no fake awards
- no fake testimonials
- no fabricated pricing
- no fabricated hours
- no fabricated services
- grounded evidence only

TECHNICAL
- responsive
- no obvious layout breakage
- usable mobile interactions
- working navigation/buttons
- reasonable performance
- no fake unsupported functionality

Do NOT invent a numeric aesthetic score.

Quality Gate may open only after:
- all 5 benchmark archetypes are produced through intended V2 chain
- Visual QA passes
- operator/human review considers them commercially presentable
- quality is repeatable
- no benchmark requires excessive manual rescue

Until then:

QUALITY GATE = CLOSED

Agent 1 may identify QUALITY_GATED prospects but they receive no active production slot.
