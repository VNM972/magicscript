# M Patrimoine — Gestion immobilière privée

Internal Magic Script portfolio project.

## Positioning

The landing page must remain explicit that M Patrimoine is:

- a private property-management / patrimonial activity in Martinique;
- an internal project, not an external Magic Script client;
- based on a real property project in development;
- oriented toward a medium/long-term vision that includes a future home adapted for people with reduced mobility.

It must not claim financial performance, client assets under management, certifications, testimonials or investment results.

## Visual identity

The supplied M Patrimoine logo has been optimized for web delivery and stored as base64 text in `public/logo.b64.txt`. The browser reconstructs the WebP image locally.
