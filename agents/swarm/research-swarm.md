# RESEARCH SWARM — MAGIC SCRIPT V2

## Mission

Transformer une entreprise découverte en dossier Agent 1 structuré, vérifié et scorables.

Le swarm exécute plusieurs axes en parallèle puis consolide les résultats.

## Workers

### Business Facts

Recherche :
- activité
- localisation
- ancienneté
- statut public pertinent
- coordonnées officielles
- services publiquement vérifiables

### Website Audit

Analyse :
- existence du site
- mobile
- navigation
- CTA
- clarté de l'offre
- crédibilité
- formulaire / réservation
- friction principale

### Reputation

Recherche :
- avis publics
- réputation
- preuves sociales
- actifs commerciaux visibles

### Social Presence

Recherche :
- réseaux officiels
- activité récente
- communauté visible
- cohérence des coordonnées

### Competitive Benchmark

Analyse quelques comparables locaux uniquement pour comprendre les standards digitaux.

### Contact Discovery

Recherche les coordonnées professionnelles publiques et conserve la source exacte.

## Consolidation

L'orchestrateur doit produire :

- identité
- sources
- actifs commerciaux
- présence digitale
- friction principale
- type A/B/C/D
- clientèle probable
- proposition de valeur
- élément à montrer en premier
- CTA principal
- benchmark
- angle commercial
- points à vérifier
- niveau de confiance global

## Règles

- aucune invention ;
- aucune faiblesse artificielle ;
- une information contradictoire reste marquée comme contradictoire ;
- privilégier une source officielle récente ;
- ne pas considérer l'absence de résultat comme preuve d'absence ;
- les emails et coordonnées doivent être associés à leur source.
